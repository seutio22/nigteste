🔄 Forçar Sincronização de Manutenção

Este script resolve o problema de sincronização entre frontend e backend.

⚠️ Problema Identificado

A manutenção existe no frontend mas não no backend, causando erro P2025.

Soluções disponíveis:

  • Opção 1: Remover manutenção do frontend (mais seguro)
  • Opção 2: Criar manutenção no backend via API
  • Opção 3: Limpar tudo e recarregar

🗑️ Opção 1: Remover do Frontend

Remove a manutenção problemática dos dados locais.

🔄 Opção 2: Criar no Backend

Tenta criar a manutenção no backend via API.

🧹 Opção 3: Limpeza Completa

Remove todos os dados locais e força recarregamento.
