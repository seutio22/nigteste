Debug - Busca de Analista

Abra o Console (F12) e execute:

// Debug da busca de analista
const userData = localStorage.getItem('auth-storage');
const masterData = localStorage.getItem('master-data-storage');

console.log('Usuário:', userData ? JSON.parse(userData) : 'Não encontrado');
console.log('Analistas:', masterData ? JSON.parse(masterData).state?.analistas : 'Não encontrado');
