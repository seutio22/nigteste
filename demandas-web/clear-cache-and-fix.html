🔧 Correção de Sincronização - Cache vs Banco

⚠️ PROBLEMA IDENTIFICADO:

O frontend tem dados em cache (localStorage) que não correspondem ao banco de dados real. O contrato que o frontend "vê" não existe no banco de dados.

📋 Passos para Correção:

  1. Limpar todo o cache do localStorage
  2. Forçar sincronização completa com a API
  3. Recarregar a página para aplicar as correções

ℹ️ O que este script faz:

  • Remove todos os dados mestres do localStorage
  • Remove dados de contratos específicos
  • Força uma nova sincronização com a API
  • Recarrega a página automaticamente
